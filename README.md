# UI/UX Design Internship Process Model & Prototype

A clean, flat-structured repository modeling the 9-stage UI/UX Design workflow, design token system, responsive landing page prototype, and report metadata generator.

## Files
- `index.html` — Responsive landing page prototype
- `styles.css` — CSS custom properties & responsive grid layout
- `app.js` — Interactive 9-stage UX workflow & state handlers
- `tokens.json` — Standardized color, typography, and spacing tokens
- `build_report.py` — Python CLI generator for structured report outlines
- `sample_config.json` — Configurable internship metadata
